### 🚀 Featured projects

**[Ibex Alarm Assist](https://github.com/usmaan677/test-alarm-llm)** — Local RAG assistant for industrial control rooms
Operators ask about an alarm and get the exact SOP procedure back, reproduced verbatim from source documents — and it *refuses* to answer when no procedure matches instead of improvising. Runs fully on-device: Ollama, ChromaDB, LlamaIndex, FastAPI, and a React operator console. Includes an evaluation suite and a per-query audit log.
`Python` · `LlamaIndex` · `Ollama` · `ChromaDB` · `FastAPI` · `React`

**[Fuji](https://github.com/iqbatrg/FUJI-hackathon)** — AI math tutor · 🏆 Gemini Hackathon winner
Snap a photo of a math problem and get a spoken, step-by-step explanation. Pipelines OCR → Gemini LLM inference → ElevenLabs text-to-speech, with prompt engineering to keep explanations clear and handle messy OCR output. React frontend, Python backend.
`React` · `Python` · `Gemini` · `ElevenLabs` · `OCR`

**[Tech-Skills](https://github.com/usmaan677/Tech-Skills)** — Job-market skills analytics pipeline
An ETL pipeline that pulls live job postings from the Adzuna API, extracts in-demand tech skills from the descriptions, and loads per-skill counts into Supabase — then ranks the most-requested skills and hiring locations. Paired with a React + Vite frontend and FastAPI service.
`Python` · `Adzuna API` · `Supabase` · `FastAPI` · `React`

**[Ethical Brand Checker](https://github.com/usmaan677/Ethical-Extension)** — Chrome extension for ethical shopping
Detects the fashion brand on the page you're browsing and shows its sustainability rating in real time, scraped live from Good On You via a Node + Puppeteer backend.
`React` · `Node.js` · `Puppeteer` · `Chrome Extension`

**[UH Clubs App](https://github.com/usmaan677/connext)** — Cross-platform mobile app for discovering University of Houston clubs, built with Expo and React Native (iOS, Android, and web).
`React Native` · `Expo` · `TypeScript`

**[UH WiFi Heatmap](https://github.com/usmaan677/UH-WiFi-Heatmap)** — Crowd-sourced live heatmap of WiFi strength across the UH campus, using GPS submissions rendered with Leaflet and backed by Firebase.
`React` · `Leaflet` · `Firebase`

**[Overloaded Cook](https://github.com/usmaan677/File-I-O-Simulation-System)** — A C++ simulation of real-time task scheduling and progression, demonstrating OOP, polymorphism, and file-based persistence.
`C++17` · `OOP` · `File I/O`
